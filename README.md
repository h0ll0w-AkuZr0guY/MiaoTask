# MiaoTask

**把重复浏览，交给助手。**

一个本地网页，管理手机、平板与模拟器的重复任务。

![MiaoTask 手绘概览：一个本地控制台，通过 USB 或 Wi-Fi 管理独立设备工作区；活动适配执行观察、执行、返回和核验循环](docs/assets/miaotask-overview.webp)

连接设备后，一键进入活动、读取任务、浏览或搜索，再返回核验进度。**当前适配淘宝淘金币双11「赚能量」活动**；设备接入、读屏、调度与记录已分层，方便后续扩展其他应用。截图与 OCR 在电脑本地处理，无需远程识别服务。

框架 ZIP 提供网页、设备控制和运行环境；**活动中心从官方 GitHub 仓库的最新 main 读取应用与活动，按需下载所选源码**。活动适配更新合并后即可获取，无需为每次活动修改重新下载框架。

## 开始使用

### 下载并启动

1. 打开 [Releases](https://github.com/h0ll0w-AkuZr0guY/MiaoTask/releases/latest)，在 **Assets** 下载 `MiaoTask-…-windows-x64.zip`。`Source code` 是源码包。
2. **完整解压**，双击 `MiaoTask.exe`，保留同目录的 `_internal/`。电脑无需另装 Python、ADB 或 OCR 模型。
3. 浏览器打开本地控制台，在 **活动中心**安装需要的应用与活动，再按下方任一方式连接设备，勾选本设备的活动并点击 **开始自动执行**。初次可在「任务设置」把本轮上限设为 2 次。活动源码单独保存在 exe 旁的 `activities/apps/`，可从活动中心打开实际位置；部分分发包已预装活动。

首次获取活动需要电脑能够访问 GitHub。安装后保存在本机，之后可在离线状态下使用已安装活动；点击刷新检查官方 main 的后续更新。已有内置活动的旧包仍可照常使用，升级时完整解压新框架。

### USB 连接

手机解锁，在系统设置中开启「开发者选项 → USB 调试」，使用支持数据传输的线连接电脑。在手机上允许这台电脑调试，然后点击网页 **连接设备**。不同厂商开启开发者选项的路径略有差异；未发现设备时检查数据线、授权弹窗和厂商驱动。

### Wi-Fi 连接

适用于支持无线调试的 **Android 11 及以上**设备。手机和电脑连接同一 Wi-Fi，或让手机连接电脑热点，展开网页 **通过 Wi-Fi 连接手机**：

| 步骤 | 在手机上 | 在网页中 |
| --- | --- | --- |
| ① 首次配对 | 开启「开发者选项 → 无线调试」，打开「使用配对码配对设备」 | 填四段 IP、配对端口和六位配对码，点击「配对手机」；保持手机弹窗打开 |
| ② 建立连接 | 关闭配对弹窗，查看无线调试**主页面**的连接端口 | IP 自动沿用，只填**连接端口**，点击「无线连接」 |
| ③ 后续使用 | 确认无线调试开启、连接地址未变化 | 选「已经配对」后连接；地址变化时按手机显示更新 |

**配对端口与连接端口通常不同。** IP 每段输满三位会自动换框，空框退格可返回上一段；也支持粘贴完整地址。校园网可能禁止设备互访，遇到超时可改用同一个个人热点。

![无线连接向导：首次配对和连接分开，四段 IP 与端口独立填写](docs/assets/feature-wifi.webp)

关闭网页后任务仍在后台运行。退出或升级时，使用 **Windows 托盘菜单**或网页底部 **退出助手**。更多连接、分身和异常处理说明见[使用文档](docs/USAGE.md)。

> 调试授权允许程序操作手机。页面变化与平台规则可能带来误操作、认证或账号风险；随机滚动不保证规避风控。登录、安全认证与真实交易由本人处理。使用前请阅读[风险与隐私](docs/SAFETY.md)。

## 功能与界面

### ✅ 活动按需安装，单台设备顺序执行

活动中心按应用展示官方仓库 main 的活动，安装后以勾选卡片加入当前设备的流水线，可调整顺序或移除。**勾选只保存计划，点击开始才执行**。同一设备的活动和分身顺序处理，不同设备继续并行。任务失败、认证或手动停止会中断当前设备流水线；任务核验规则保持原有方式。

活动安装、更新和卸载需所有设备操作结束。卸载保留日记录；活动包包含可执行 Python 代码，只安装经过审阅的可信活动，校验不提供沙箱隔离。活动所需的新第三方依赖仍需更新框架运行环境。

以下图片截取自正常 **1920 × 1080 桌面视口**中的对应功能区域，保留原比例。工作区名称和任务示例仅用于说明交互，不代表任务完成记录。

### ✅ 同页管理，多设备并行

点击 **添加设备**创建工作区，切换标签查看各自的设置、任务、日志和画面。每台设备独立开始、暂停和停止；勾选设备后可 **应用当前设置并启动**。同一物理设备的重复连接会被拦截，同一手机内的分身仍按队列串行执行。

![设备工作区：添加设备、切换标签与批量启动；图中为尚未连接的示例工作区](docs/assets/feature-devices.webp)

MuMu 通过实际运行实例发现连接端口；预览按设备比例显示，识别坐标回映到原屏幕。模拟器未登录时可检查唤醒与入口，工具不会代办登录。

### ✅ 任务由程序识别，也能随时调整

浏览、搜索、跳转及累计奖励按活动规则处理，每次开始和返回都会重读列表。行内 **执行 / 跳过**调整可执行队列，**不会立即启动任务**；当前步骤先安全结束，下次选择时生效。已完成或必须人工处理的任务不能强制加入，右侧保留实际处理状态。

![任务队列的交互示例：执行与跳过并排，完成及人工任务不可选择；图中为合成任务演示](docs/assets/feature-queue.webp)

任务选择、失败次数、已确认缺失的应用与统计按 **设备、应用、活动、实例、日期**保存。同日重启继续使用，次日重新判断；失败现场可在本地查看和导出，公开前需自行脱敏。

### ✅ 按需设置，保持简单的开始路径

**任务设置 / 滚动节奏 / 高级选项**分别管理执行范围、滑动参数和识别恢复；**应用分身**默认收起。搜索使用原生填字与提交兜底，不安装或替换输入法。跨应用返回优先逐层检查，必要时有限重启恢复所选实例。

![滚动节奏设置：距离、时长、额外间隔和同方向连续次数均可调整范围](docs/assets/feature-scroll.webp)
