# 公共配置与适用范围

本表对应 `backend/core/config/defaults.json`。配置传递路径为网页表单 → Controller 校验 → 用户目录保存 → 活动配置快照 → 执行策略。`framework_overrides()` 统一筛选公共字段，切换活动、跨应用流水线、保存和恢复均复用它；应用入口、活动专用搜索词等业务字段不跨活动复制，公共任务词表则随配置继承。

下表区分页面配置与兼容字段；调用/离线回归不等于所有设备组合都已真机验证。

## 页面可调参数

| 参数 | 默认值 / 范围 | 消费位置与边界 | 审查结果 |
| --- | --- | --- | --- |
| `default_browse_seconds` | 17 / 1～120秒 | 首轮及重试基础浏览取设置与页面要求较大值 | 首轮不做中途OCR；实际CUDA在结束时检查并有界补滑，CPU到时返回列表核验；初始已见明确完成可返回 |
| `browse_recheck_rounds` | 3 / 整数0～10 | 上次核验失败后，基础浏览并停1秒检查；必要时补滑1秒再检查 | 初始检查之外最多补滑指定次数，仍受任务硬上限与当天失败预算约束 |
| `max_attempts` | 3 / 1～3次 | 通用调度与今日任务策略；核验进度增加会清除连续失败预算 | 已检查；认证、主动停止不计普通失败 |
| `max_tasks` | 80 / 1～300次 | 每个活动、实例本次运行的尝试上限，领奖尝试也占次数 | 已修复结束后复查重新取得一份预算的问题；不代表整台设备跨活动总上限 |
| `enabled_task_kinds` | browse/search/visit/claim | 通用循环选择任务类型 | 已检查；至少选一项，不能强制执行人工任务 |
| `task_search_keywords` | 123、2026、100 / 最多100词，每词1～40字符 | 公共词表；本次活动会话的普通任务搜索随机抽取词 | 留空沿用活动默认输入；不替换活动入口专用词，原生填写受限时可退回数字搜索 |
| `skip_task_keywords` | 原有任务跳过词 / 最多100词，每词1～40字符 | 标题或说明包含任一词即跳过，纯文本、英文不区分大小写 | 保存至系统用户配置，不随日期过期；清空任务标记不删除，任务执行按钮不能绕过；修改后下次启动生效 |
| `claim_rewards` | true | 领奖任务门控，以及月月赚显式领取按钮 | 前端与“累计领奖”合并为一个入口；自动到账奖励仍可核验，不属于点击领取 |
| `scroll_browse` | true | 淘宝标准浏览/搜索的连续滑动 | 已检查；不禁止为查找任务而滚动列表；月月赚短停留不消费此参数 |
| `swipe_distance_min/max` | 18%～36% / 8%～50% | 标准手势在当前屏幕可操作区域内采样 | 已检查；网页百分数转成0～1比例，非固定像素 |
| `swipe_duration_min/max` | 0.25～0.65 / 0.15～1.5秒 | 标准手势持续时间 | 已检查；不是整项浏览时长；网络与命令发送开销另计 |
| `swipe_interval_min/max` | 0 / 0～3秒 | 标准浏览两次手势之间的主动等待 | 已检查；0不插入等待；浏览按实际经过时间计时，非零间隔可能减少实际滑动次数 |
| `swipe_burst_min/max` | 1～3 / 1～5次 | 标准手势同方向连续次数 | 已检查；活动自定义列表翻页不受此参数约束 |
| `allow_cross_app` | true | 通用调度过滤已识别目标应用、淘宝跳转与返回策略 | 已检查；关闭不等于系统级禁止外部App启动，未知跳转仍须识别与返回 |
| `ocr` | true | ScreenReader及活动可选视觉复查 | 已检查；关闭后保留原生控件，不能承诺H5任务仍可识别 |
| `compressed_screenshots` | false | Android主屏按需同步采集 | 已检查；关闭为全分辨率PNG，开启同尺寸JPEG；其他驱动/屏幕保留原路径，执行时预览只随必要观察更新，空闲预览保留原路径 |
| `screenshot_quality` | 70 / 整数30～95 | 开启压缩时传给截图RPC的JPEG质量参数 | 已可调整；数值越高清晰度越高，非固定体积百分比，不改变原始分辨率和坐标 |
| `reset_after_activity` | false | 正常结束后清理当前实例任务标记，再执行一次复查 | 已检查；保留累计统计与本次尝试上限，安全停止不自动继续 |
| `keep_screen_on` | false | 开始唤醒并临时修改设备自动息屏时间 | 正常结束恢复，强制杀进程/断联不能保证恢复 |
| `screen_timeout_minutes` | 10 / 1～1440分钟 | 开启上述开关时设置设备自动息屏超时 | 是设备超时值，不是功能有效期，不模拟额外触屏 |
| `minimum_volume` | false | 支持Android的媒体流设置、读回与恢复 | 已检查；不改铃声/闹钟，失败提示，原生HDC暂不支持 |
| `minimum_brightness` | false | 支持Android的自动亮度模式与亮度临时设置 | 已检查；结束恢复；不关闭屏幕，不支持时提示 |
| `clear_clipboard` | true | 开始执行前调用设备端清空接口 | 已检查；不读取内容、不更换输入法；不支持时提示后继续 |

## 保留在源码配置的框架参数

| 参数 | 默认值 / 范围 | 实际含义 |
| --- | --- | --- |
| `visit_seconds` | 8 / 1～120秒 | 无页面明确时长时，淘宝普通访问任务的停留时间；不是浏览任务的通用时长 |
| `max_task_seconds` | 90 / 5～180秒 | 标准浏览阶段硬上限；不包含打开任务、返回列表和核验整个流程 |
| `page_timeout` | 15 / 3～60秒 | 入口加载与页面导航等待预算；串行传输保留驱动超时，不固定等待15秒 |
| `return_timeout` | 22 / 5～90秒 | 恢复导航阶段的基础预算；页面转场与有界重启可增加阶段预算，非整个任务总超时 |
| `max_back_steps` | 4 / 1～8次 | 导航一次恢复阶段的返回次数上限，桌面后有界恢复会重新开始阶段 |
| `max_scroll_pages` | 8 / 1～20次 | 通用循环及支持活动的列表扫描/翻页预算，不是浏览时滑动次数 |

这些参数有实际调用者，保留原兼容接口；没有为了展示完整而把所有内部预算放到网页。

## 活动差异与入口

淘宝五项活动复用标准浏览策略；支付宝月月赚保留自身的 `browse_shortcut_seconds`（默认5秒）短停留策略，因此不消费上表的浏览基础时长、补滑次数和连续手势参数。不得用“公共”一词推断每个活动都支持同一种流程。新增活动应在文档声明支持范围，优先复用公共组件；不得静默接受配置后用另一套常量覆盖。

网页统一自动识别当前页面，必要时恢复所选应用并导航；已删除重复的“特殊入口方式”开关。CLI/API保留 `auto_open=False` 的旧兼容行为，该字段属于启动意图，不保存为公共配置。

调整配置后点击应用设置或开始执行。已开始的运行使用自己的配置快照，不承诺中途热改；设备切换丢弃未应用的旧表单，活动切换继承已应用公共配置。更详细的调用契约见 [公共接口](https://github.com/h0ll0w-AkuZr0guY/MiaoTask/blob/main/docs/REUSABLE_INTERFACES.md)，验证要求见 [测试与构建](https://github.com/h0ll0w-AkuZr0guY/MiaoTask/blob/main/docs/BUILDING.md)。


兼容字段 `browse_extra_seconds`、`browse_check_interval` 不再参与标准两段式浏览，页面已移除；`settle_seconds` 保留给已有日常页策略（如非标准停留动作），不叠加到首轮基础时长。并发采集/CPU预算的试验字段已移除，旧偏好经framework_overrides过滤，不进入新运行配置。


任务文案的跳过条件统一由公共 `skip_task_keywords` 控制，默认词表集中在 `backend/core/config/defaults.json`，包含头条、游戏、拉人、答题、下单等原有条件。按标题与说明作字面包含匹配，不再由淘宝分类器写死关键词或特殊例外；已完成行仍保持完成状态。移除词后重新开始即可放行，执行按钮不绕过现有词表。能力不支持、应用缺失、日失败预算与页面安全认证仍由原有运行契约处理。

普通任务每次使用 `random.choice` 从 `task_search_keywords` 抽词，允许连续抽中相同词；留空才退回活动的任务默认输入。活动入口搜索使用原名称，不使用商品词。数字可直接输入，中文自定义词沿用现有原生填写及有界备用路径，不更换输入法。

旧用户配置缺少词表或词表为空时，一次性填入默认词并写入用户偏好迁移标记；非空自定义词表保持原样。迁移后用户再次主动清空不会重新填入。清空任务标记不删除词表或重置累计统计。

媒体音量命令读回未生效时依次回退至兼容入口与Android AudioService的`set-volume 3`，仅操作媒体流；不可读或恢复失败会提示手动处理，不以音量键修改其他声音流。


## 控制台级识别与下载设置

| 字段 | 默认值 | 生效范围 |
| --- | --- | --- |
| `ocr_device` | `auto` | 整个本地服务，`auto/cpu/cuda`；所有设备空闲时切换，实际GPU不可用可回退CPU |
| `download_proxy` | 空文本 | 整个服务的活动目录与源码下载；空值沿用系统，`off`直连，或HTTP/HTTPS代理 |

两项保存在既有用户偏好中，保留任务词表和设备配置；环境变量 `MIAO_OCR_DEVICE` / `MIAO_DOWNLOAD_PROXY` 优先。它们不更改活动的 `ocr` 配置，月月赚默认继续优先使用原生UI；CUDA选择不把所有活动都改为强制OCR。实际CUDA同应用标准浏览的末尾补滑沿用 `browse_recheck_rounds`，visit与活动短停留保持原有含义。截图失焦复读是设备安全策略，不新增用户重试开关。

淘宝任务页与搜索结果的渲染等待独立于浏览时长：进入前短等1.2秒再读屏，CPU保持单次就绪识别；快速CUDA才补帧确认控件位置。选择CUDA但实际回退CPU时不会沿用GPU复核频率。无需为动画等待调大浏览秒数或增加CPU识别次数。
