# 待发布贡献

普通 PR 只在下方追加单行条目：`* 【新增|优化|修复|文档|维护】用户可见变化或贡献说明 (#PR / @作者)`。
分类需选择其中一个；PR 号创建后补充，也可先写关联 Issue 或作者。同一贡献不重复追加，不在此文件写设备信息和测试流水。
维护者构建发布时在副本中汇总并审阅，已收录条目从副本清空，后续贡献继续追加。
