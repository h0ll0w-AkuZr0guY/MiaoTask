# 使用说明

## 启动与 USB 连接

本版本仅支持搭载 **Apple Silicon（M 系列芯片，`arm64`）** 的 macOS，固定使用 macOS 系统原生 Vision OCR，并仅保留 **Android ADB USB 有线连接**（不支持 Wi-Fi 无线调试或模拟器连接）。

* **便携包启动**：从 [Releases](https://github.com/heyunl/MiaoTask-macOS/releases/latest) 下载 `MiaoTask-…-macos-arm64.zip`，完整解压后在终端运行 `./MiaoTask`，保留同目录的 `_internal/`。若首次运行提示未验证开发者，可在「系统设置 → 隐私与安全性」允许运行。
* **源码启动**：在仓库目录双击 `start.command` 或在终端运行 `./start.command`。若本机尚未安装 `adb`，请先执行 `brew install android-platform-tools`（或安装 Android SDK `platform-tools`）。

手机保持解锁，开启「开发者选项 → USB 调试」，使用支持数据传输的 USB 线连接 Mac，并在手机弹窗中点击「允许 USB 调试」。在网页控制台点击左侧设备卡片的齿轮或虚线「添加设备」，点击「刷新 USB 列表」，选择已发现的 USB 设备（也可直接填写 USB 设备序列号），再点击「连接 USB 设备 / 创建并连接」。设备名称也在同一弹窗修改，原有的第一台设备同样可以改名。

默认控制台地址为 `http://127.0.0.1:8765`，被其他程序占用时会自动选择空闲端口。未授权时程序会等待本人在手机上确认，不会修改 ADB 密钥或代替手机授权。始终无法发现设备时，请检查 USB 数据线（排除仅充电线）、扩展坞供电及手机上的 USB 用途/调试开关。

## 多设备管理

左侧虚线「添加设备」打开名称与 USB 连接窗口。直接连接会先创建工作区，再将 USB 连接提交给该工作区；也可点「仅创建设备」，稍后再连。添加后显示为设备卡片，下方继续保留新增入口。齿轮打开已有设备的名称与连接设置，可保存名称、重连或移除；执行期间仅允许改名，重连和移除需先停止。

卡片以灰色表示未连接、绿色表示已连接、红色表示连接异常，连接中使用当前主题的强调色；状态文字同时显示。连续三次预览失败也会提示异常，后续成功取图恢复，不把一次慢截图当成设备断开，不中断任务。

点击卡片切换活动、任务、日志和预览，其他设备继续运行；卡片前的复选框用于批量选择，不改变当前展示设备。每台设备可分别开始、暂停、继续或停止；工作区、名称与连接只保留在本次服务期间，重开后重新添加和连接，日累计记录继续保留。窄窗口下设备栏改为页面顶部的横向列表。

勾选多个设备后，点击设备栏底部固定的「一键启动」，将当前页面的活动计划与公共设置发送给这些设备；每台独立执行，单台异常不停止其他设备。未连接、忙碌或配置不兼容的设备会单独反馈原因。批量操作使用各设备自己选定的应用实例，不把当前设备的分身选择复制过去。「唤醒」「停止」也作用于已勾选设备。默认最多 8 个工作区。

「唤醒」仅打开各设备选定的应用，适合检查接入状态，不会执行任务或代办登录。空闲设备可移除，正在操作的设备需先停止；移除不删除日记录。退出助手会停止全部设备。

## 活动中心

顶部保留活动中心、公共设置、排行榜、画面与提示、外观等全局入口。当前设备的「活动计划」中先切换应用，再勾选其下活动；不同应用的活动可以加入同一个设备计划，由执行顺序统一排序。

下载的活动源码默认位于可执行文件旁的 `activities/apps/<应用>/activities/<活动>/`（源码运行时位于仓库根目录的 `activities/`）；安装记录和目录缓存也保存在 `activities/` 中。「活动中心」显示实际路径，点击「打开文件夹」即可在 macOS 访达（Finder）中查看。请通过活动中心更新或卸载，修改源码前先停止全部设备。安装目录只读时会改用 `~/Library/Application Support/MiaoTask/activities/`，界面显示回退后的实际位置。

在「活动中心」刷新官方仓库 main 的应用与活动列表，安装需要的项目，再在当前设备的活动标签上勾选。活动按应用分组紧凑展示；保存位置默认折叠，需要时展开查看。点击弹窗外侧、按 Esc 或点击右上角「关闭」均可关闭，关闭界面不会取消已经提交的安装操作。

只下载所选活动及其应用共享源码，不下载其他应用的活动或额外环境。展开「执行顺序」，用箭头调整顺序；移除仅从当前计划取消，不卸载活动。每台设备最多选择 16 个不同活动，计划保留在本次服务期间。

点击「开始自动执行」后，该设备依次执行已选活动；同一应用沿用本设备明确选择的实例，不同应用分别保存实例选择。新连接设备会重新核定实例，不复用上一台手机的分身队列。切换到没有主实例的应用时，需要先明确选择分身。先核定当前页面，有任务列表时直接读取，否则自动进入对应活动。

活动显示「已结束」表示本次运行正常返回，具体任务成功仍以进度核验和统计为准。人工认证、身份不符、未处理异常或用户停止会中断当前设备的后续活动；其他设备不受影响。

安装、更新或卸载活动前，请停止所有设备的任务、识别与连接操作；暂停的任务仍占用执行线程，也需要停止。目录切换期间不能启动设备操作。卸载保留设备、实例与日期的任务记录；当前活动被卸载时，相应设备需重新选择活动并连接。

活动包是可执行 Python 代码，使用当前进程的权限。官方地址约束、文件摘要、路径检查和兼容校验用于核对来源及完整性，不构成隔离执行环境。活动包不自动安装 Python 依赖；缺少框架运行库时需升级框架。

首次安装与更新需要电脑能够访问 GitHub。已安装源码保留在本机，断网时仍可运行；目录缓存用于展示上次获取的信息，不能代表已经获取最新提交。

## 执行与设置

点击「开始自动执行」，助手按所选活动进入对应页面，确认任务列表后执行；每次返回和重新开始都会更新列表。多个活动可在同一设备的计划中排序执行，记录彼此独立。

入口优先使用可读控件，画布菜单和弹窗以 macOS 系统 Vision OCR 复核；坐标来自当前页面，不按个人设备分辨率换算预设点击点。未找到官方搜索卡片时不会进入同名商品。

支付宝「月月赚」通过首页全局搜索填写活动名，再打开官方入口。当前停在快递等小程序的局部搜索时，先有界返回再进入全局搜索；仅解析浏览、逛类任务，其他商业任务不自动操作。

普通浏览搜索使用固定数字或配置的检索词，避免原输入法将字母留在候选区而未实际填入；查找活动入口仍使用活动名称。助手不安装或切换系统输入法。

| 入口 | 可调整内容 |
| --- | --- |
| 任务设置 | 基础浏览时长、补滑复查次数、今日失败及本轮上限、任务类型、累计领奖、公共词表 |
| 滚动节奏 | 距离、时长、同方向连续次数和额外间隔的最小/最大值 |
| 高级选项 | 跨应用访问与返回、OCR 开关、下载代理、截图质量及设备运行选项 |
| 设备连接弹窗 | 自动执行全部应用分身，默认关闭 |

顶部导航「公共设置」集中提供任务、滚动和高级三个分类，作用于当前设备的活动计划；批量启动时发送给已勾选设备。高级选项中的「开始前清空设备剪贴板」默认开启，用于减少残留助力链接弹窗，可关闭并随公共配置保存；只清空设备端，不读取、上传或恢复旧内容，也不更换输入法。

修改后点击「应用设置」，也可关闭弹窗后直接开始。切换设备会读取目标设备设置。配置保存到 `~/Library/Application Support/MiaoTask/preferences.json`，升级保留。由于 macOS Apple Silicon 系统 Vision OCR 具备原生硬件加速，淘宝标准浏览在首轮基础时长（默认 17 秒）结束时也会读取页面完成状态，未完成则按上限有界补滑；页面出现明确完成提示后，按「完成后随机返回延时」设定随机等待 0～设定值毫秒再返回（默认 0～1000 毫秒）。补滑复查默认 3 次，同一任务今日失败上限默认 3 次，本轮最多 80 次。

设备连接弹窗提供「自动执行全部应用分身」开关，默认关闭。开启后按当前应用实际识别顺序串行执行主应用与全部分身，无需手选或排序；活动流水线切换应用后重新读取该应用的实例。每个实例独立使用本轮上限、核验与日记录。

暂停后可继续，停止后可重新开始。遇到安全认证、登录、账号授权或支付提示时，程序会自动停止操作并弹出 macOS 系统提醒，由本人手动完成验证后再回到网页点击「开始自动执行」。

任务行的“执行 / 跳过”是队列选择，点击执行不会立即开始操作。正在进行的步骤先安全结束，下一次选择任务时应用调整；已完成及必须人工处理的任务不能强制加入。

## 固定系统 OCR 与下载代理

* **本地 OCR 引擎**：固定为 **macOS Apple Silicon（M 系列芯片）系统 Vision OCR**（`ocr_device = "vision"`），自动启用高精度简繁中文与英文识别（`zh-Hans` / `zh-Hant` / `en-US`）。无需安装 RapidOCR、ONNX Runtime、CUDA 或 DirectML 扩展包；在非 Apple Silicon 环境调用本地 OCR 会直接返回明确错误提示。
* **活动下载代理**：公共设置「高级选项」中的活动下载代理可填 `http(s)://host:port` 地址或 `off`（强制直连），留空跟随系统代理。该偏好作用于整个控制台，保存在用户配置中；不应在公开截图或日志中暴露代理凭据。

## 重新识别、词表与截图策略

「公共设置 → 公共词表」可维护两份列表，词之间使用中文/英文分号、空格或换行：

* **任务搜索输入词**：例如 `手机壳；雨伞；2026`，普通任务搜索随机使用；留空保留活动默认值。进入淘金币、月月赚等活动需要的专用词不受影响。
* **常驻跳过关键词**：例如 `微博；快手；头条`，标题或说明包含任一词就跳过。按普通文本匹配，英文不区分大小写。

同一应用内手动换登录账号无法可靠自动识别，请先停止，再点击执行按钮旁的「清空任务标记」；仅清理当前设备、活动、实例的执行选择、失败预算和不可用任务判断，保留今日累计、诊断和其他实例记录。

公共设置「高级选项」提供「浏览时使用压缩截图」（默认关闭，JPEG 质量默认 70、范围 30～95）、「执行期间保持亮屏」、「最低媒体音量」和「最低亮度」。默认值、调用位置和各活动适用范围见 [配置核验表](CONFIGURATION.md)。

截图提示无法核定前台时，框架会先在 8 秒总预算内复读显示摘要和窗口详情；消息通知临时占用前台时，助手暂停输入并等待恢复，不打开消息。预算耗尽、真实分身不一致或切到另一显示屏仍会停止。

## 画面、日志与统计

顶部导航「画面与提示」显示或收起右侧栏，「外观」提供暖橙、湖蓝、午夜三种主题。收起右栏时不再额外请求网页预览；下方「运行日志」与任务列表共用切换栏，内容随当前设备切换。

记录按 **设备 + 应用 + 活动 + 实例 + 自然日** 保存在 `~/Library/Application Support/MiaoTask`（便携版）或仓库 `runtime/`（源码运行），独立于解压目录；更新时删除旧程序文件夹不会清空这些记录。顶部「排行榜」按匿名设备标识汇总，不会展示原始设备序列号。「失败现场与反馈」可导出当日诊断 ZIP，公开分享前请遮挡个人隐私信息，详见[风险与隐私](SAFETY.md)。

## 退出、升级与离线恢复

在运行终端按 `Ctrl+C`（或结束 `MiaoTask` 进程）可安全停止所有设备任务并退出服务；退出时仅清理本次启动且路径属于当前安装的内置 ADB 进程，不会终止用户自己启动的系统 ADB 服务。

升级前先退出旧助手，将新 ZIP 完整解压到新目录后启动，不混用新旧可执行文件和 `_internal/` 运行库。「离线恢复」使用随包（`_internal/activity-recovery`）或本机保留（`activities/recovery`）的已校验活动 ZIP，断网时也可恢复已下载过的活动。
