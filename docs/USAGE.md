# 使用说明

## 启动与连接

从 [Releases](https://github.com/h0ll0w-AkuZr0guY/MiaoTask/releases/latest) 的 Assets 下载 Windows x64 ZIP，完整解压后运行 `MiaoTask.exe`，不要移走 `_internal/`。`Source code` 是源码包。

手机保持解锁，开启 USB 调试、连接数据线，并在手机上允许这台电脑调试。在网页点击「连接设备」；只有一台可用手机时自动选择，多台时选择对应设备。

默认地址为 `http://127.0.0.1:8765`，被其他程序占用时会选择空闲端口。首次未发现 USB 手机时会尝试兼容 ADB 后端；未授权时等待本人确认，无法代替手机授权。始终无法发现设备时，请检查数据线、调试开关及厂商 USB 驱动。

### Wi-Fi 无线连接（Android 11 及以上）

手机和电脑连接同一 Wi-Fi，展开网页「通过 Wi-Fi 连接手机」。

1. 手机打开「开发者选项 → 无线调试」，开启后点击「使用配对码配对设备」。在网页「首次配对」填写弹窗中的 **IP:端口** 和 **六位配对码**，点击「配对手机」，保持手机弹窗打开直到配对成功。
2. 关闭手机配对弹窗，在网页「连接手机」沿用配对 IP，填写无线调试**主页面**的**连接端口**，点击「无线连接」。配对端口和连接端口通常不同。
3. 设备就绪后照常开始任务。之后可选择「已经配对」直接连接；手机端撤销配对后需要重新配对。无线调试重开或换网后，地址可能改变。

无线配对默认使用四个 IP 框和一个端口框，输入三位自动前进，空框退格返回上一段。配对成功后连接 IP 自动复用，只填写无线调试主页面的连接端口；换网时修改 IP。也可粘贴完整 IPv4 地址，IPv6 在“完整地址 / IPv6”中填写。地址仅在当前页面的设备工作区间保留，配对码不保存。

「查找无线设备」可列出广播地址，需要本人核对选择；发现失败也可手填。校园网、企业网可能阻止设备互访，可改连同一个个人热点。不会扫描校园网地址段、修改防火墙或开启无认证 TCP 调试。配对码不写入日志或配置；ADB 按系统机制保留电脑配对身份。使用结束后可在手机关闭无线调试、撤销不再使用的电脑授权。USB 与无线连接共用同一手机、实例和日期的统计。

## 多设备与模拟器

顶部「添加设备」创建独立工作区，可选择已连接设备，或先添加后在当前工作区使用 Wi-Fi 向导。点击设备标签切换下方的设置、任务、日志和预览，其他设备继续运行。每台设备可分别开始、暂停、继续或停止；工作区连接只保留在本次服务期间，重开后重新添加和连接，日累计记录继续保留。

勾选多个设备后，点击「应用当前设置并启动」，将当前页面的任务与滚动配置发送给这些设备；每台独立执行，单台异常不停止其他设备。活动不同、未连接或忙碌的设备会单独反馈原因。批量操作使用各设备自己选定的应用实例，不把当前设备的分身选择复制过去。默认最多 8 个工作区，实际容量取决于电脑、网络和 OCR 负载。

「唤醒所选应用」仅打开各设备选定的应用，适合未登录的模拟器进行接入检查，不会执行任务或代办登录。空闲设备可移除，正在操作的设备需先停止；移除不删除日记录。退出助手会停止全部设备。

模拟器先在 MuMu 中启动，再点击添加面板的「查找 MuMu 模拟器」，读取厂商提供的实际端口。未发现时，可手动填入模拟器诊断页的 ADB 地址。不会猜端口、修改模拟器配置或启动未运行的实例。连接后自动按实际横竖屏和应用所在显示屏识别，预览保留比例；遇到登录或受保护页面会暂停，需要本人处理。

## 执行与设置

保持「自动进入活动」，点击「开始自动执行」。助手尝试从首页「领淘金币」进入活动，打开「赚能量 / 去赚能量」菜单，读到任务行后执行；每次返回和重新开始都会更新列表。

| 入口 | 可调整内容 |
| --- | --- |
| 任务设置 | 浏览时长及额外时长、重试和本轮上限、任务类型、累计领奖 |
| 滚动节奏 | 距离、时长、同方向连续次数和额外间隔的最小/最大值 |
| 高级选项 | 跨应用访问与返回、OCR、从手机当前页面开始 |
| 应用分身 | 选择一个实例，或勾选多个并调整顺序 |

这些选项默认收起。修改后点击「应用设置」，也可直接开始，执行时会使用当前表单。设置保留在当前服务期间。15秒浏览默认增加10秒及2秒缓冲，识别到完成提示可提前返回；额外滑动间隔默认0，实际速度仍受手机与识别耗时影响。

默认使用主应用。展开「应用分身」后可选择其他实例；队列中每个实例独立使用本轮上限，上一实例正常结束才开始下一个。异常、人工验证、实例身份不符或手动停止会中断队列。运行中不能切换实例配置；运行前收起该功能会取消队列并恢复主应用。

暂停后可继续，停止后可重新开始。自动进入失败时，可以手动打开任务列表，再在「高级选项」选择「从手机当前页面开始」。普通异常会逐层返回并重读页面，键盘收起后继续返回；确认任务列表即继续执行。返回达到上限时先回到桌面，确认后最多重启恢复一次，始终使用所选实例。认证、登录、授权或支付提示由本人处理，不会自动通过。

淘宝启动动画或活动弹窗可能遮挡入口，助手会先尝试返回再重新定位；无法覆盖的弹窗或入口变化仍需手动处理。

任务行的“执行 / 跳过”是队列选择，点击执行不会立即开始操作。先由识别结果给出默认选择，可实时调整尚未完成的任务；开始自动执行后按正常流程处理已选任务。正在进行的步骤先安全结束，下一次选择任务时应用调整；本轮已结束时需再次开始。右侧继续显示运行、完成或失败状态。已完成及必须人工处理的任务不能强制加入。

## 统计与反馈

记录按 **设备 + 淘宝实例 + 自然日**保存，同日重开延续，次日重新判断缺失应用和不可用任务；不同分身独立，同一实例内手动切换账号仍共用当天记录。任务是否完成以返回后的进度为准，访问次数不等于成功次数。

失败次数与手动跳过按设备、应用、活动、实例、日期保存在本地，重启不清零。普通失败达到设置中的上限后当天跳过，第二天重新判断；点击执行会重置该任务的失败预算并加入队列，但不会绕过应用缺失、安全认证和任务类型设置。任务标题或执行规则更换后作为新任务识别，位置变化不会清除原选择。

「失败现场与反馈」显示当前实例当天的固定目录，可导出诊断 ZIP。反馈建议包含版本、机型、系统、任务名称、起始页面和复现步骤。原始截图不会自动打码，请先遮挡设备码、昵称、头像、金额和搜索历史。数据位置及边界见[风险与隐私](SAFETY.md)。

## 退出与升级

关闭浏览器后任务继续，额外预览随后停止。双击 Windows 托盘图标可打开控制台，右键「停止任务并退出助手」结束服务；网页底部「退出助手」同样有效。

升级前退出旧助手，将新 ZIP 完整解压到新目录后启动，不混用新旧 exe 和运行库。刷新网页后可在页脚查看版本；用户数据不随解压目录清空。
