# 使用说明

## 启动与连接

从 [Releases](https://github.com/h0ll0w-AkuZr0guY/MiaoTask/releases/latest) 的 Assets 下载 Windows x64 ZIP，完整解压后运行 `MiaoTask.exe`，不要移走 `_internal/`。`Source code` 是源码包。

v0.1.3 发布 ZIP 默认预装双11活动，其他活动在「活动中心」从官方 GitHub main 获取。框架包含设备控制、网页与运行环境；活动源码与框架分开保存，后续可独立更新。

手机保持解锁，开启 USB 调试、连接数据线，并在手机上允许这台电脑调试。点击左侧设备卡片的齿轮，或虚线「添加设备」，在连接弹窗中选择已发现设备或填写地址，再点击「连接设备 / 创建并连接」。设备名称也在同一弹窗修改，原有的第一台设备同样可以改名。

默认地址为 `http://127.0.0.1:8765`，被其他程序占用时会选择空闲端口。首次未发现 USB 手机时会尝试兼容 ADB 后端；未授权时等待本人确认，无法代替手机授权。始终无法发现设备时，请检查数据线、调试开关及厂商 USB 驱动。

### Wi-Fi 无线连接（Android 11 及以上）

手机和电脑连接同一 Wi-Fi，在左侧设备连接弹窗切换「Wi-Fi 无线」。

1. 手机打开「开发者选项 → 无线调试」，开启后点击「使用配对码配对设备」。在网页「首次配对」填写弹窗中的 **IP:端口** 和 **六位配对码**，点击「配对手机」，保持手机弹窗打开直到配对成功。
2. 关闭手机配对弹窗，在网页「连接手机」沿用配对 IP，填写无线调试**主页面**的**连接端口**，点击「无线连接」。配对端口和连接端口通常不同。
3. 设备就绪后照常开始任务。之后可选择「已经配对」直接连接；手机端撤销配对后需要重新配对。无线调试重开或换网后，地址可能改变。

无线配对默认使用四个 IP 框和一个端口框，输入三位自动前进，空框退格返回上一段。配对成功后连接 IP 自动复用，只填写无线调试主页面的连接端口；换网时修改 IP。也可粘贴完整 IPv4 地址，IPv6 在“完整地址 / IPv6”中填写。无线区域顶部只有一个「使用完整地址 / IPv6」切换，统一控制配对和连接两项地址的输入样式；两项地址的端口仍各自独立。地址仅在当前页面的设备工作区间保留，配对码不保存。

「查找无线设备」可列出广播地址，需要本人核对选择；发现失败也可手填。校园网、企业网可能阻止设备互访，可改连同一个个人热点。不会扫描校园网地址段、修改防火墙或开启无认证 TCP 调试。配对码不写入日志或配置；ADB 按系统机制保留电脑配对身份。使用结束后可在手机关闭无线调试、撤销不再使用的电脑授权。USB 与无线连接共用同一手机、实例和日期的统计。

## 多设备与模拟器

左侧虚线「添加设备」打开名称与连接窗口，支持 USB、模拟器和 Wi-Fi。直接连接会先创建工作区，再将连接提交给该工作区；也可点「仅创建设备」，稍后再连。添加后显示为设备卡片，下方继续保留新增入口。齿轮打开已有设备的名称与连接设置，可保存名称、重连或移除；执行期间仅允许改名，重连和移除需先停止。

卡片以灰色表示未连接、绿色表示已连接、红色表示连接异常，连接中使用当前主题的强调色；状态文字同时显示。连续三次预览失败也会提示异常，后续成功取图恢复，不把一次慢截图当成设备断开，不中断任务。没有额外取图时不进行独立网络探活，颜色反映最近观察结果。

点击卡片切换活动、任务、日志和预览，其他设备继续运行；卡片前的复选框用于批量选择，不改变当前展示设备。每台设备可分别开始、暂停、继续或停止；工作区、名称与连接只保留在本次服务期间，重开后重新添加和连接，日累计记录继续保留。窄窗口下设备栏改为页面顶部的横向列表。

勾选多个设备后，点击设备栏底部固定的「一键启动」，将当前页面的活动计划与公共设置发送给这些设备；每台独立执行，单台异常不停止其他设备。未连接、忙碌或配置不兼容的设备会单独反馈原因。批量操作使用各设备自己选定的应用实例，不把当前设备的分身选择复制过去。「唤醒」「停止」也作用于已勾选设备。默认最多 8 个工作区，实际容量取决于电脑、网络和 OCR 负载。

「唤醒」仅打开各设备选定的应用，适合未登录的模拟器进行接入检查，不会执行任务或代办登录。空闲设备可移除，正在操作的设备需先停止；移除不删除日记录。退出助手会停止全部设备。

模拟器先在 MuMu 中启动，再点击添加面板的「查找 MuMu 模拟器」，读取厂商提供的实际端口。未发现时，可手动填入模拟器诊断页的 ADB 地址。不会猜端口、修改模拟器配置或启动未运行的实例。连接后自动按实际横竖屏和应用所在显示屏识别，预览保留比例；遇到登录或受保护页面会暂停，需要本人处理。

## 活动中心

顶部保留活动中心、公共设置、排行榜、画面与提示、外观等全局入口。当前设备的「活动计划」中先切换应用，再勾选其下活动；不同应用的活动可以加入同一个设备计划，由执行顺序统一排序。

下载的活动源码默认位于 `MiaoTask.exe` 旁的 `activities/apps/<应用>/activities/<活动>/`；安装记录和目录缓存也保存在 `activities/` 中。「活动中心」显示实际路径，点击「打开文件夹」即可查看。请通过活动中心更新或卸载，修改源码前先停止全部设备。安装目录只读时会改用用户数据根下的 `activities/`，界面显示回退后的实际位置。旧版 `%LOCALAPPDATA%/MiaoTask/plugins` 在首次使用空的新目录时复制迁移，原文件保留，已有预装活动不会被覆盖。

在「活动中心」刷新官方仓库 main 的应用与活动列表，安装需要的项目，再在当前设备的活动标签上勾选。活动按应用分组紧凑展示；保存位置默认折叠，需要时展开查看。点击弹窗外侧、按 Esc 或点击右上角「关闭」均可关闭，关闭界面不会取消已经提交的安装操作。

只下载所选活动及其应用共享源码，不下载其他应用的活动或额外环境。展开「执行顺序」，用箭头调整顺序；移除仅从当前计划取消，不卸载活动。每台设备最多选择 16 个不同活动，计划保留在本次服务期间。

点击「开始自动执行」后，该设备依次执行已选活动；同一应用沿用本设备明确选择的实例，不同应用分别保存实例选择。新连接设备会重新核定实例，不复用上一台手机的分身队列。切换到没有主实例的应用时，需要先明确选择分身。多个活动必须开启自动进入；从当前页面开始仅适合单个活动。

活动显示「已结束」表示本次运行正常返回，具体任务成功仍以进度核验和统计为准。人工认证、身份不符、未处理异常或用户停止会中断当前设备的后续活动；其他设备不受影响。

安装、更新或卸载活动前，请停止所有设备的任务、识别与连接操作；暂停的任务仍占用执行线程，也需要停止。目录切换期间不能启动设备操作。卸载保留设备、实例与日期的任务记录；当前活动被卸载时，相应设备需重新选择活动并连接。

活动包是可执行 Python 代码，使用当前进程的权限。官方地址约束、文件摘要、路径检查和兼容校验用于核对来源及完整性，不构成隔离执行环境。活动包不自动安装 Python 依赖；缺少框架运行库时需升级框架。

首次安装与更新需要电脑能够访问 GitHub。已安装源码保留在本机，断网时仍可运行；目录缓存用于展示上次获取的信息，不能代表已经获取最新提交。活动更新从官方 main 获取，不需要发布新的框架或独立的活动 Release；界面提示兼容性问题时先更新框架。下载安装失败会保留原有可用活动和本地任务记录。

## 执行与设置

保持「自动进入活动」，点击「开始自动执行」。助手按所选活动进入对应页面，确认任务列表后执行；每次返回和重新开始都会更新列表。多个活动可在同一设备的计划中排序执行，记录彼此独立。

### 淘宝活动

| 活动 | ID | 入口与执行范围 |
| --- | --- | --- |
| 双11赚能量 | `double11` | 首页「领淘金币」→「赚能量 / 去赚能量」；保留原有浏览、搜索、跳转和累计奖励流程 |
| 淘金币日常 | `coins` | 「领淘金币 / 淘金币」→必要时切「日常版」→「赚更多金币」；识别任务进度、奖励圆钮、清单卡片、搜索和可领取奖励 |
| 芭芭农场 | `farm` | 首页或「全部频道」中的「芭芭农场」→「集肥料」；处理浏览、访问和明确的签到领取，答题、施肥、浇水等留给本人 |
| 红包签到 | `cash-signin` | 首页「红包签到」；仅处理每日签到及带明确金额的定时奖励，必要时按奖励页提示浏览；本轮已核验的奖励不会反复领取 |
| 淘宝成就中心 | `achievements` | 「成就中心」或搜索结果中的官方「开启我的淘宝成就 → 点击进入」；必要时切到「我的成就 → 做任务领成就」，处理每日签到、成就点领取与可识别任务。不要求为成就点任务开启商城的实物打卡；遇到强制地址设置页仍停止，由本人决定是否参与 |

以上日常活动目前仅声明 Android 驱动。入口优先使用可读控件，画布菜单和弹窗以本地 OCR 复核；坐标来自当前页面，不按个人设备分辨率换算预设点击点。未找到官方搜索卡片时不会进入同名商品。

现金签到的提现推广优先点击可确认的关闭按钮，已确认推广而关闭图标不可读时尝试一次返回，不点击「开」「提现」「点击参与」或修改收货地址。领取后核对完成文案、任务进度或对应余额变化，按钮文字拆分、点击和停留本身不算成功。各账号的任务和资格不同，未开启活动可能需要本人先处理。

普通浏览搜索使用固定数字检索词，避免原输入法将字母留在候选区而未实际填入；查找活动入口仍使用活动名称。助手不安装或切换系统输入法。部分设备的可读控件失效时会改用可见搜索框与系统输入能力；这类驱动修复需更新框架，单独更新活动无法改变旧 exe 的底层请求超时。

淘金币和农场中断后重新自动执行，会先有界地回到任务列表顶部，再按当天记录继续检查。任务执行后的返回保留当前列表位置；安全验证仍停止等待本人处理，不会靠重启绕过。

同一应用的多个已安装活动共用应用工具源码。更新提示共享文件冲突时，停止所有设备，卸载该应用旧活动后，从同一仓库提交重新安装所需活动；卸载保留日记录，不要手动混合不同提交的共享 Python 文件。

| 入口 | 可调整内容 |
| --- | --- |
| 任务设置 | 浏览时长及额外时长、重试和本轮上限、任务类型、累计领奖 |
| 滚动节奏 | 距离、时长、同方向连续次数和额外间隔的最小/最大值 |
| 高级选项 | 跨应用访问与返回、OCR、从手机当前页面开始 |
| 设备连接弹窗 | 自动执行全部应用分身，默认关闭 |

顶部导航「公共设置」集中提供任务、滚动和高级三个分类，作用于当前设备的活动计划；批量启动时发送给已勾选设备。新增淘宝活动复用这些参数，入口和识别词表随活动提供，目前不需要额外的应用或活动设置。分身开关在设备连接弹窗中配置。

修改后点击「应用设置」，也可关闭弹窗后直接开始，执行时会使用当前表单；点击外侧或按 Esc 关闭不会清除本页修改。切换设备会关闭弹窗并读取目标设备的设置，未应用的修改不带到其他设备。设置保留在当前服务期间。15秒浏览默认增加10秒及2秒缓冲，识别到完成提示可提前返回；额外滑动间隔默认0，实际速度仍受手机与识别耗时影响。

设备连接弹窗提供「自动执行全部应用分身」开关，默认关闭。开启后按当前应用实际识别顺序串行执行主应用与全部分身，无需手选或排序；活动流水线切换应用后重新读取该应用的实例。每个实例独立使用本轮上限、核验与日记录。关闭后使用主应用；异常、人工认证、实例失效或手动停止会中断该设备后续队列。开关按当前服务中的设备工作区分别保存，批量启动不复制其他设备的分身开关。

暂停后可继续，停止后可重新开始。自动进入失败时，可以手动打开任务列表，再在「高级选项」选择「从手机当前页面开始」。普通异常会逐层返回并重读页面，键盘收起后继续返回；确认任务列表即继续执行。返回达到上限时先回到桌面，确认后最多重启恢复一次，始终使用所选实例。认证、登录、账号授权或支付提示由本人处理。普通应用跳转先确认页面语义，再匹配“允许 / 本次允许 / 确认”等按钮；无法完成时返回并跳过当前任务，不将其他任务一起封禁。

淘宝启动动画或活动弹窗可能遮挡入口，助手会先尝试返回再重新定位；无法覆盖的弹窗或入口变化仍需手动处理。

任务行的“执行 / 跳过”是队列选择，点击执行不会立即开始操作。先由识别结果给出默认选择，可实时调整尚未完成的任务；开始自动执行后按正常流程处理已选任务。正在进行的步骤先安全结束，下一次选择任务时应用调整；本轮已结束时需再次开始。右侧继续显示运行、完成或失败状态。已完成及必须人工处理的任务不能强制加入。

## 画面与日志

顶部导航「画面与提示」显示或收起右侧栏，浏览器会记住该偏好。桌面宽度下，手机画面与折叠的小提示随页面滚动保持可见；窄窗口下改为普通纵向布局。「画面宽度」滑条调整侧栏预览大小，浏览器会记住该偏好；「放大」打开当前设备的实时大图，点击外侧或按 Esc 可关闭。切换设备会关闭大图，等待新设备画面，避免混淆。

「外观」提供暖橙、湖蓝、午夜三种主题，点击立即生效并保存在当前浏览器，同一浏览器的其他打开页面同步变化。主题只调整界面颜色和外观，保留设备状态颜色含义，不修改任务参数、应用选择或运行记录。

这些控制不改变任务识别或执行节奏；收起右栏时不再额外请求网页预览。截图由任务与预览调度自动更新，需要时可点击「刷新」主动读取。下方「运行日志」与任务列表共用切换栏，内容随当前设备切换。

## 统计与反馈

记录按 **设备 + 应用 + 活动 + 实例 + 自然日**保存，同日重开延续，次日重新判断缺失应用和不可用任务；不同活动和分身独立，同一实例内手动切换账号仍共用当天记录。任务是否完成以返回后的进度为准，访问次数不等于成功次数。

Windows 便携版的累计与诊断默认保存在 `%LOCALAPPDATA%/MiaoTask`，独立于解压目录；更新时删除旧程序文件夹不会清空这些记录。显式配置数据目录时使用对应位置。

顶部「排行榜」按匿名设备标识＋应用汇总，也可切到设备＋应用＋活动；同设备的分身合并统计。支持全部日期或今日，点击运行时长、核验完成、跳过、失败表头切换降序。当前在线设备同时显示工作区名称，历史设备以匿名代号区分；不会展示原始设备码。点击刷新读取最新日记录，不另建计数、不上传。运行时长沿用任务累计用时；诊断截图数量与人工验证次数不直接计入失败。统计读取当前框架的活动日记录，未迁移的旧版根目录记录不重复加入；无效记录保留原文件并提示未计入。

失败次数与手动跳过按设备、应用、活动、实例、日期保存在本地，重启不清零。普通失败达到设置中的上限后当天跳过，第二天重新判断；点击执行会重置该任务的失败预算并加入队列，但不会绕过应用缺失、安全认证和任务类型设置。任务标题或执行规则更换后作为新任务识别，位置变化不会清除原选择。

「失败现场与反馈」显示当前实例当天的固定目录，可导出诊断 ZIP。反馈建议包含版本、机型、系统、任务名称、起始页面和复现步骤。原始截图不会自动打码，请先遮挡设备码、昵称、头像、金额和搜索历史。数据位置及边界见[风险与隐私](SAFETY.md)。

## 退出与升级

关闭浏览器后任务继续，额外预览随后停止。双击 Windows 托盘图标可打开控制台，右键「停止任务并退出助手」结束服务；网页不再提供底部退出按钮。

升级前退出旧助手，将新 ZIP 完整解压到新目录后启动，不混用新旧 exe 和运行库。刷新网页后可在页脚查看版本；用户数据不随解压目录清空。新版本的活动源码单独保存在 exe 旁；升级时可在活动中心重新安装，或在退出助手后将旧包的整个 `activities/` 复制到新目录，不要只复制其中某个 Python 文件。
